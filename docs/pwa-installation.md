# PWA Installation

## Android

Open `https://fms.cmll.in` in a supported browser. Use the in-app Install button when available or the browser menu's install option. Enable notifications from the Notifications screen after login.

## iPhone And iPad

Open `https://fms.cmll.in` in Safari, tap Share, then Add to Home Screen. Open the installed Home Screen app before enabling push notifications. Notification permission must be requested from a user action.

## Desktop Browsers

Use the browser install icon or the in-app Install button where supported. If unavailable, use the browser menu's install app option.

## Offline Behaviour

The app caches static assets and an offline fallback page. Live dashboard/API data remains network-first and is not cached by the service worker.
